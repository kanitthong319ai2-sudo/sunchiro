# Multi-Course Learning Hub v1.15

## สิ่งที่อยู่ในชุดนี้
- `index.html` หน้าเว็บศูนย์รวมหลักสูตร รองรับหลายหลักสูตรในหน้าเดียว
- `content/generative-ai-multimedia.json` เนื้อหาหลักสูตรแรกแบบแยกหน่วย/บทเรียน/Workshop/Prompt
- `supabase/migration_v1.1.sql` โครงสร้างฐานข้อมูลรองรับหลายหลักสูตร พร้อม RLS
- ผู้เรียนยังไม่ต้อง Login
- โครงสร้างเตรียมต่อระบบสมาชิกและบันทึกความก้าวหน้าในระยะถัดไป

## ทดลองใช้งานบนเครื่อง
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง (เช่น VS Code Live Server) ไม่แนะนำเปิด `file://` เพราะหน้าเว็บโหลด JSON ด้วย fetch

## นำขึ้น GitHub Pages
คัดลอก `index.html`, โฟลเดอร์ `content/` และไฟล์อื่นตามต้องการไปไว้ในโฟลเดอร์เว็บไซต์ของ repository แล้ว commit/push ตามวิธีที่ใช้อยู่

## Supabase
1. เปิด Supabase SQL Editor
2. ตรวจสอบว่า helper function `public.is_admin()` ในโปรเจกต์เดิมมีอยู่และตรวจ role/status อย่างถูกต้อง
3. รัน `supabase/migration_v1.1.sql`
4. Migration นี้สร้างตารางใหม่เท่านั้น ไม่แก้ไขตาราง LMS เดิม
5. นโยบายให้บุคคลทั่วไปอ่านเฉพาะเนื้อหาที่ publish และให้ผู้ดูแลที่ผ่าน `is_admin()` จัดการข้อมูลได้

## หมายเหตุสำคัญ
- ไฟล์หน้าเว็บเวอร์ชันนี้อ่านเนื้อหาจาก JSON เพื่อให้เริ่มใช้งาน/ตรวจสอบได้ทันที ยังไม่ได้เชื่อมการอ่าน/บันทึกข้อมูลกับ Supabase และยังไม่มีหน้าจอแก้ไขหลังบ้าน
- SQL เป็นโครงสร้างฐานข้อมูลพร้อมนโยบายความปลอดภัย แต่ยังไม่ได้รันบน Supabase จริง
- การแก้ไข JSON ในชุดนี้ทำได้โดยตรง; ระยะถัดไปเชื่อม Admin Editor กับ Supabase เพื่อเพิ่ม/แก้ไข/เผยแพร่รายส่วนโดยไม่แก้โค้ด
- ไม่ต้องใช้ OpenAI API Key สำหรับอ่านหลักสูตรหรือคัดลอก Prompt
- ชื่อเมนูและความสามารถของเครื่องมือ AI อาจเปลี่ยนตามแพ็กเกจและประเทศ ให้ยึดหน้าจอจริงของผู้เรียน
- เนื้อหาหลักยึดคู่มือการฝึกอบรม 30 ชั่วโมงที่ให้ไว้; เพิ่มเติมเฉพาะโครงสร้างเว็บไซต์และคำอธิบายการใช้งานระบบ
